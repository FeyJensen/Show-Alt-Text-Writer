# 🚀 START HERE - Alt Text Generator for Showit

Welcome! Your Chrome extension is complete and ready to use.

## ⚡ 3-Minute Quick Start

### 1️⃣ Get API Key (1 minute)
- Go to: https://aistudio.google.com/app/apikey
- Click "Create API key"
- Copy the key

### 2️⃣ Install Extension (1 minute)
- Open: `chrome://extensions/`
- Enable "Developer mode" (top-right toggle)
- Click "Load unpacked"
- Select the `AltTextGoogleExtension` folder

### 3️⃣ Configure (1 minute)
- Click the extension icon (shows "ALT")
- Click "⚙️ Settings"
- Paste your API key
- Click "💾 Save API Key"

**That's it!** 🎉

---

## 🎯 How to Use

1. Go to any Showit website
2. Click the extension icon in your toolbar
3. Click "Generate Alt Text"
4. Watch it process images and add descriptions
5. See the results in the popup

## ❓ Quick Questions

**Q: Where's the API key stored?**  
A: Locally on your computer, encrypted in Chrome's sync storage. Never shared.

**Q: Does it work on all Showit pages?**  
A: Yes! Any page on showit.co with images.

**Q: Is it free?**  
A: Yes! Google provides a free tier for the API.

**Q: Does my privacy matter?**  
A: Absolutely! Images are only sent to Google for processing. Not stored or logged.

**Q: Can I modify the generated alt text?**  
A: Yes! The alt text is added to the page. You can edit it like normal text.
